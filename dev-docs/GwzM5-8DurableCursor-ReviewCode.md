## Findings

### [P2-1] §3.3 / §4.3: the "later durable row vs factless earlier owner" decode-rejection claim contradicts the amendment's own graceful-degradation and equivalence-test sections — BLOCKING

Amendment §3.3 (:296-302): "a later durable row (**artifact**, skip, or reset marker) while an earlier owner's row shows neither artifacts nor markers is now a record-bytes contradiction, rejected by checked-open validation … without any repository read." Repeated as §4.3's third contradiction item, "later-durable-row-vs-empty-earlier-row" (:325-329).

The claim is unimplementable as stated, on the amendment's own terms:

- A later **artifact-only** row beside a factless (typically **absent**) earlier-owner row is a *legitimate pre-amendment shape*: today's cursor live-skips a clean owner writing no row at all (`cursor.rs:29-38` at HEAD — `backup_complete` :247 and the no-ids arm of `stash_complete` :279-282 return complete with zero durable trace), then writes the next owner's evidence row. Every existing fixture with a clean early owner has this shape.
- §4.2 (:314-324) explicitly requires those records to keep classifying via the verbatim live re-proof path, and §8.2(b) (:465-472) pins "the markers stripped to the pre-amendment shape — identical classification verdicts". §5 (:349-357) forbids a version bump, so the decoder has no writer discriminator: it cannot reject the shape for post-amendment writers without rejecting it for pre-amendment ones.
- If instead "an earlier owner's **row** shows neither artifacts nor markers" means a *present*-but-empty row, the item is vacuous: an all-absent row is already invalid independent of any later row (§2.2 row 1; `validate/preservation.rs:121-123`), and "is **now** a record-bytes contradiction" is then false — it always was.

The sound decode-terminal core exists and the amendment elsewhere states it correctly: a later row **carrying one of the new markers** self-certifies post-amendment write discipline, and §7.3's applied TransitionDesign delta says precisely "contradiction rejection now includes **marker** contradictions" (:435-437). The fix is to align §3.3's parenthetical and §4.3 item 3 to that narrow rule (drop "artifact" from the later-row set, or condition the rejection on marker presence somewhere in the record), and either delete "empty-earlier-row" or state it as the already-covered §2.2 row-1 case. Until fixed, the controlling document licenses two divergent implementations of restart legality on real records.
