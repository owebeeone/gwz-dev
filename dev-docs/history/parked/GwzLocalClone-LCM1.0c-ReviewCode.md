## 1. Findings

### [P2-1] `admitted_local_peer` admits a local directory that libgit2 routes to the SSH network transport (any path containing `:` on macOS/Linux)

- **Location.** `gwz-core/src/git/gitbackend/transport.rs:148-171` (`admitted_local_peer`: refuses `://`, `git@`/`ssh@` prefixes, non-directories; admits everything else), consumed by `fetch_anonymous` (`:173-196`, `repo.remote_anonymous(&peer)` then `fetch`) and `push_anonymous` (`:198-255`). Contract text: `src/git/gitbackend/contract.rs:742-748` ("`url` must be an existing local repository path, never a URL … attaches no credential or network helper"), `transport.rs:148-150` ("libgit2 selects its local transport for a plain path, so nothing here can reach a network or a credential helper"), `docs/GitBackend.md:58-60` ("libgit2's local transport is the only one that can run").
- **Violated invariant.** Boundaries §3 "Writes, locks and transport" (the adapter "takes admitted local repository paths … uses no credentials/network helpers"); design §6.2 ("Fetch through anonymous local transport"); F51 P2-3's closure evidence ("Real anonymous transfers through the port … no persisted remote"), which this port exists to supply.
- **Reproduction (verified by reading the linked libgit2, `libgit2-sys 0.18.8+1.9.7`, `transport.c` `transport_find_fn`).** For a peer string with no URL prefix, libgit2 on non-Windows checks `strrchr(url, ':')` **before** the `git_fs_path_isdir(url)` test (transport.c lines 22–31 of the function: the `#ifdef GIT_WIN32` directory check at 8–15 is compiled out; the `:` check at 22–25 selects `transport_find_by_url("ssh://")`, which exists because gwz-core builds `git2` with the `ssh` feature and `libgit2-sys/build.rs:86,245` defines `GIT_SSH`; the `#ifndef GIT_WIN32` directory check at 28–31 is then skipped because `definition` is set). So on a macOS/Linux host: `mkdir -p /tmp/gwz:lane/src`, initialise a repository with one commit there, initialise a receiver, then `backend.fetch_anonymous(&receiver, "/tmp/gwz:lane/src", &["+refs/heads/main:refs/gwz/local-imports/t1"])` — `admitted_local_peer` passes (`is_dir()` is true), `remote_anonymous` succeeds, `fetch` connects through `git_transport_smart` + the SSH subtransport, which parses the string as an scp-style `host:path`, attempts a host lookup/connection with no credential callback, and fails; `git_error` maps it to `git_command_failed` (`verify_checkout_state.rs:132-134`). The import ref is never created. `push_anonymous` takes the same path. Windows is unaffected (directory check first). Directory names containing `:` are legal and ordinary on macOS (Finder displays `/` as `:`), and the design's default destination `../<root-dir>-<name>` inherits the parent path.
- **Impact.** A family whose root or any member lives under a `:`-containing path cannot import or push through the ports on the recorded development platform; the failure is reported as a Git/network error for a purely local operation (diagnosability); the port's stated "local-only, never a network transport" guarantee — the load-bearing claim for F51 P2-3's closure and for lanes X and T — is false for that path class. No credential exposure (no callbacks are attached), hence not P0.
- **Required correction.** After admission, hand libgit2 an unambiguous local URL instead of the bare path: canonicalise (`std::fs::canonicalize`) and pass `url::Url::from_file_path(..)` (gwz-core already depends on `url`). A `file://` string matches the transport table's `file://` prefix (`transport.c:36`) before the `:` heuristic runs, and libgit2's local transport accepts it (`transports/local.c:222,397` → `git_fs_path_from_url_or_path`, `util/fs_path.c:1580-1586`). Keep the caller-facing refusal of `file://` inputs as is (the existing test expects it). The minimal alternative — refuse any admitted path containing `:` with `invalid_request` naming the colon — is acceptable if the operator prefers a refusal over a conversion; either is a change to `transport.rs` only (unpinned).
- **Closure test.** In `src/local_clone/tests/transport.rs`, a `#[cfg(unix)]` case whose source and bare-hub directories contain `:` in a path component: `fetch_anonymous` creates the import ref holding the source commit and `push_anonymous` updates the hub (or, under the refusal remedy, both refuse `invalid_request` before any effect and `remotes()` stays empty). Re-run `cargo test -p gwz-core --lib local_clone::tests::transport`.
