The proposed per-key dispatcher permits ID 2 to reach the peer before ID 1. It then reports ID 1 delivered even though the mux ignored it, leaving that operation waiting for a stream that never opened. This is a third new architectural root on this design object after the serial-data/control stall and the cross-lane opening barrier.
