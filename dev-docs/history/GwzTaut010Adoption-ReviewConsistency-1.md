### [P3-6] Claim 5 enumerates "four generator paths" and scopes the site-directory rule to "the last three", omitting gwz-py's `scripts/regen_protocol.py`, whose provenance rule is weaker
- **Location:** brief §3 claim 5 (line 60): "All four generator paths take the released taut-proto 0.10.0: production gwz-core, the candidate, the consumer and gwz-transport. The last three accept it only from the interpreter's site directories." Also §6 line 108 ("in all four generator paths"). `gwz-py/scripts/regen_protocol.py` pins `TAUT_GENERATOR_VERSION = "0.10.0"` (line 27) and regenerates `api.py` and `gwz.ir.json` (brief §2 gwz-py lists it as a pin and describes its output as "regenerated"), so it is a fifth generator path.
- **Invariant violated:** exactness of counts and of the set a claim ranges over. gwz-py's generator checks the installed version through `importlib.metadata.version` (lines 53–56) and pops `PYTHONPATH` for the child (line 39), but has neither the site-directory binding nor the module-origin check the sentence attributes, by omission, to every non-production generator.
- **Reproduction:** grep `regen_protocol.py` for `site`, `sysconfig`, `sys.modules`, `__file__` → none; the version check runs in the parent process, whose `sys.path` still carries `PYTHONPATH`, so a metadata-carrying shadow satisfies it while the child generates with whatever is installed (a mismatch that `--check`, the drift check and the byte-identity claim catch, so the effect is bounded).
- **Impact:** a reader of claim 5 believes the site-directory rule covers every taut-proto-consuming generator but gwz-core's production one; it does not cover gwz-py's, and the brief nowhere says so.
- **Remedy:** either name `regen_protocol.py` as the fifth path and state its rule (installed version equals the pin; `PYTHONPATH` dropped for generation), or give it the same binding as the other three and add the metadata-carrying shadow test to gwz-py's suite; §6's "all four" follows the choice.
- **Closure test:** claim 5's enumeration equals the set of scripts in the four repos that pin a taut-proto version and emit protocol artifacts (`grep -l TAUT_GENERATOR_VERSION\|"taut-proto"` over `protocol/regen.py`, the two gwz-core pins, gwz-transport's pin and `regen_protocol.py` → five), and each named path's rule is stated.
