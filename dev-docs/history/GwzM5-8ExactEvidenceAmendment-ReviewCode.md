## 1. Fix A — `disable_filters(true)` (VERIFIED)

**(a) Mechanism, verified in the Cargo.lock-pinned vendored sources** (git2 0.21.0; libgit2-sys 0.18.7+1.9.6): git2 `build.rs:501/597` maps `disable_filters` onto raw `git_checkout_options.disable_filters`. libgit2 1.9.6 `checkout.c:1556` — with the flag set, `git_filter_list__load(..., GIT_FILTER_TO_WORKTREE, ...)` is skipped entirely; `git_filter_list_stream_blob(NULL, ...)` → `stream_list_init` (`filter.c`) treats a NULL list as direct passthrough to the target stream — raw ODB bytes, CRLF/ident/registered to-worktree drivers all bypassed. The conflict-content write path (`checkout.c:2130`) honors the flag equally. Critically, the SAFE-checkout dirty analysis (`checkout_is_workdir_modified`, `checkout.c:176-249`) computes workdir oids via `git_diff__oid_for_entry` — filter-aware and **independent** of `disable_filters` — so previously-smudged-but-clean files are still classified unmodified and get overwritten; the flag changes only the write direction. No new conflict/refusal risk introduced at either site.

**(b) Site enumeration COMPLETE.** Independent sweep of `src/` for `checkout_tree`/`checkout_head`/`checkout_index`/`set_head`/`.reset(`/`stash_*`/`CheckoutBuilder` found exactly the amendment's table: the two recovery-grade sites got the flag (`merge_recovery.rs:157` in `abort_merge` (force), `:211` in `set_branch_target_checked` (safe)); the seven forward/user-facing sites are untouched as tabled (`merge_prepared.rs:255,328`; `refs.rs:35,136`; `repository.rs:81,108,133`), plus user stash apply/pop (porcelain restore, correctly out of scope) and the two `stash_save` sites (the flagged residual). Root preservation `ResetAttachedRef` routes through `set_branch_target_checked` (`preservation_root.rs:124`) — covered. Every per-site decision checks out: each flagged site's result is re-judged by the raw-byte model (`observe_v1_participant_rollback` → `clean_checkout` → `checkout_matches_commit_except`; `observe_reset` → `capture_normalized`); no untouched site is raw-byte-judged **as a mutation edge**.

**(c) Unix/no-filter safety:** with no to-worktree filters configured, skipping the filter-list load is byte-identical to streaming through an empty list; where a Unix user *has* configured crlf/ident, raw-writing at these two sites is the designed semantic (disclosed). Empirically: full gate suites green on this macOS tree (below).

The raw-byte observations are **full-tree** (`clean_checkout` → `checkout_matches_commit_except`, participants.rs:235-252), and they gate normal rollback preflight (`abort/preflight.rs:69,83,98`), no-mutation verification, and recovery re-entry (`rolling_back_recovery.rs:44`).
